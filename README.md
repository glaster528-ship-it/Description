# «Herobrine» — Minecraft-анимация в Blender

Короткометражный бой на 30 секунд (720 кадров, 24 к/с, 1920×804, 2.39:1) в стиле
Minecraft-анимаций с ванильными текстурами 1.21.11: ночь, туман в долине, Стив против Herobrine.

## Синхрон

- Все события заданы константами кадров, и анимация, и эффекты, и звук считаются из них же:
  каждый звук стоит на кадре своего события (удар — кадр 400, луч — 496, удар в землю — 578 и т.д.).
- Контакты рассчитаны, а не на глаз: ноги ставятся на блоки по FK на каждом кадре,
  кулак Herobrine попадает точно в клинок на кадре удара, остриё меча входит в землю там, где воронка.
- Музыка (Precipice) стартует с 98.75 с трека — смещение подобрано анализом ударных долей так,
  чтобы сильные доли совпали с ударами.
- Не меняйте частоту кадров (24): анимация запечена по кадрам.

## Как запустить

Нужен **Blender 5.2** (проверено на 5.2.3 LTS). Minecraft Java 1.21.11 желательно (если игры нет —
скрипт скачает файлы с серверов Mojang, как это делает лаунчер).

1. Скачайте репозиторий и откройте `minecraft_herobrine.blend`.
2. Нажмите **Allow Execution** — скрипт сам найдёт игру и подключит оригинальные текстуры и звуки
   (появятся папки `textures/` и `sounds/` рядом с файлом). Сохраните (Ctrl+S).
3. Если вопроса не было: вкладка **Scripting** → `mc_assets.py` → **Run Script**
   (или N-панель → вкладка **Minecraft** → «Загрузить ресурсы Minecraft»).

Где ищется игра: `%APPDATA%\.minecraft` (официальный лаунчер, TLauncher), `~/.minecraft`,
Prism/MultiMC, Modrinth, CurseForge. Путь к `1.21.11.jar` можно указать вручную на панели Minecraft.

## Рендер

Всё настроено: Cycles (256 сэмплов, адаптивно, OpenImageDenoise), motion blur, глубина резкости,
AgX, блум и виньетка в композитинге, камеры переключаются маркерами на таймлайне.

- Видео сразу со звуком: Render → Render Animation (Ctrl+F12) → `render/herobrine_0001-0720.mp4`.
- Надёжнее для долгого рендера: Output → PNG, рендер кадров, потом сборка со звуком в Video Sequencer.
- Видеокарта: Edit → Preferences → System → Cycles Render Devices (OptiX/CUDA/HIP/Metal).
- Туман: объект `Atmosphere`. Скрыть его — рендер заметно быстрее, но без дымки.

## Файлы

- `minecraft_herobrine.blend` — готовая сцена (без файлов игры).
- `scripts/build_scene.py` — сборка сцены с нуля: мир, хореография, эффекты, камеры, свет, звуковые метки.
  `blender -b --factory-startup --python scripts/build_scene.py`
- `scripts/mclib.py` — риг персонажа (сгибы в локтях/коленях/пояснице, пиксельная мимика: глаза,
  моргание, брови, рот), воксельный мир, частицы, камеры.
- `scripts/mc_assets.py` — загрузчик ресурсов (встроен и в `.blend`).

Анимация запечена ключами на каждом кадре на обычных арматурах `Steve_Rig` и `Herobrine_Rig` —
её можно править в Graph Editor / Dope Sheet. Мимика — shape keys на объектах `*_Face`.

Текстуры и звуки Minecraft принадлежат Mojang и в репозиторий не входят.
