# Minecraft Sunset — анимация в Blender

Короткометражка на 30 секунд (720 кадров, 24 к/с, 1920×1080) в стиле Minecraft:
ванильные текстуры 1.21.11, пиксели без сглаживания, Cycles, закатное небо, звук игры.

## Как запустить

Нужен **Blender 5.2** (проверено на 5.2.3 LTS) и установленный **Minecraft Java 1.21.11**
(достаточно один раз запустить эту версию в лаунчере).

1. Скачайте проект целиком и откройте `minecraft_sunset.blend`.
2. Если Blender спросит про автозапуск скриптов — нажмите **Allow Execution**.
   Скрипт сам найдёт игру и подключит текстуры и звуки (папки `textures/` и `sounds/`
   появятся рядом с `.blend`). Сохраните файл (Ctrl+S).
3. Если вопроса не было: вкладка **Scripting** → текст `mc_assets.py` → **Run Script**
   (или в 3D-окне N → вкладка **Minecraft** → «Загрузить ресурсы Minecraft»).

Где ищется игра: `%APPDATA%\.minecraft` (официальный лаунчер, TLauncher), macOS/Linux
`~/.minecraft`, Prism/MultiMC, Modrinth, CurseForge. Если игра не найдена, скрипт скачает
клиент 1.21.11 и нужные звуки с официальных серверов Mojang (как это делает лаунчер).
Можно указать путь к `1.21.11.jar` вручную на панели Minecraft.

Без интерфейса:

```bash
blender -b minecraft_sunset.blend --python scripts/mc_assets.py -- --save
```

## Рендер

Всё уже настроено: Cycles, 384 сэмпла с адаптивностью и денойзом OpenImageDenoise,
motion blur, AgX, глубина резкости, камеры переключаются маркерами на таймлайне.

- **Видео со звуком сразу**: Render → Render Animation (Ctrl+F12) → `render/minecraft_sunset_0001-0720.mp4`
  (H.264 + AAC).
- **Надёжнее для долгого рендера**: Output Properties → File Format → PNG, отрендерить
  кадры, затем собрать их со звуком в Video Sequencer. При вылете рендер можно продолжить.
- Видеокарта: Edit → Preferences → System → Cycles Render Devices (OptiX/CUDA/HIP/Metal).
- Дымка и лучи: материал объекта `Atmosphere`, параметр Density (0 — выключить).
  Сэмплы: Render Properties → Sampling.

## Что внутри

- `minecraft_sunset.blend` — готовая сцена (без файлов игры).
- `scripts/build_scene.py` — генератор сцены: рельеф, деревья, риги, вся анимация, камеры,
  свет, звуковые метки. Пересобрать: `blender -b --factory-startup --python scripts/build_scene.py`.
- `scripts/mc_assets.py` — загрузчик ресурсов (тот же, что встроен в `.blend`).

Риги `Steve_Rig` и `Creeper_Rig` — обычные арматуры (root, body, head, руки/ноги),
анимация лежит ключами на каждом кадре, её можно править в Graph Editor или Dope Sheet.
Пропорции и UV моделей ванильные (64×64 скин Стива с внешним слоем, 64×32 крипер),
раздувание и мигание крипера — по формулам `CreeperRenderer` из игры.

Текстуры и звуки Minecraft принадлежат Mojang и в репозиторий не входят.
